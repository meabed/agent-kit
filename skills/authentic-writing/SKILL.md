# Write specific, credible copy

## Ground the draft

Identify the audience, purpose, desired action, channel, voice samples, and facts the source material
can prove. Research current claims when the task requires it. Mark an unsupported fact as unknown or
remove it; never invent statistics, customers, outcomes, quotes, features, or credentials.

## Draft in the brand's real language

- Use concrete nouns and active verbs a customer or practitioner would use.
- Prefer precise benefits, mechanisms, and examples over superlatives.
- Match supplied voice samples without copying private details into public copy.
- Vary phrasing across pages and products; do not assign every offering the same metaphor or claim.
- Remove stock transitions, canned conclusions, empty intensifiers, and buzzwords such as
  "revolutionary", "game-changing", "cutting-edge", or "seamless" when they do not add testable
  meaning.
- Keep technical language when the audience uses it; explain it when the audience does not.

## Edit for credibility

Read the draft aloud. Replace abstract claims with proof, shorten throat-clearing, remove repeated
ideas, and compare several word choices where a phrase still sounds generic. Keep the result no
longer than the source unless the user requested expansion.

Before delivering, verify every factual claim, product name, link, and number. Return the finished
copy and list uncertain claims only when the user asks for an audit.
