description: Rewrite supplied communication into an answer-first, MECE pyramid.
argument-hint: <draft and audience>
---

Use the `pyramid-communication` skill to rewrite the supplied draft for its intended audience.

Lead with one actionable answer, organize two to four non-overlapping supports beneath it, attach
evidence to the support it proves, and end with the decision or next action. Use an SCQA opener only
for a high-stakes memo, proposal, or presentation that benefits from it.

Return the polished communication only unless the user asks for the audit.
