# Pyramid rewrite

Rewrite the supplied draft for the named audience.

1. Put the answer, recommendation, or decision in the first sentence.
2. Support it with two to four mutually exclusive points that collectively cover the decision.
3. Place facts, examples, and numbers under the point they prove.
4. Remove background that does not change the decision, repeated claims, generic filler, and
   unsupported assertions.
5. End with the exact action, owner, or decision needed when one exists.

Use `Situation / Complication / Question / Answer` only when the communication is high-stakes and
the audience needs that setup. Return only the rewritten draft unless an audit is requested.
